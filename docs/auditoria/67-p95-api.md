# P1-13 — p95 real da API (22/11/2026)

> **Escopo:** o que a série `api_request_samples` (0330/0331) realmente mede.
> Não é estimativa, não é SLO de `api_request_probes` e não é número de produção.

## Consulta e resultado (banco local do seed, pg15)

```sql
select count(*),
       round(percentile_cont(0.95) within group (order by duration_ms)::numeric, 1)
from api_request_samples
where status between 200 and 399
  and created_at > now() - interval '7 days';
```

| Medida | Valor |
|---|---:|
| Amostras 2xx/3xx na janela de 7 dias | **536** |
| **p95 real** | **505,0 ms** |
| Alvo do SLO | ≤ 800 ms |
| Veredito | **dentro do alvo** (505 < 800) |

Primeira amostra: 2026-11-16 08:37 UTC; última: 2026-11-20 18:42 UTC.
Distribuição por rota quente: `/api/v1/conversations` 135 (p95 518,3 ms),
`/api/v1/financeiro/dashboard` 128 (497,7), `/api/v1/invoices` 123 (504,9),
`/api/v1/commercial-orders` 122 (510,7), `/api/v1/contacts` 118 (505,9).

## O que este número NÃO é

- **Não é p95 de produção.** A série local é alimentada por instrumentos/QA;
  a instalação de produção entrou na 1.63.1 agora e não há janela de tráfego
  suficiente para afirmar nada lá. O número de produção só pode ser citado
  quando a série da VPS acumular amostras 2xx/3xx das rotas quentes — até lá,
  a afirmação correta é "sem série suficiente", não "está verde".
- **Não inclui 5xx/4xx** no percentil: o alvo fala de latência de respostas
  bem-sucedidas (`fn_slo_api_resumo` usa o mesmo filtro 2xx/3xx).
- **Não é o p95 de uma rota isolada**; o valor agregado é o do SLO. As rotas
  individualizadas estão na tabela acima, para diagnóstico.

## Como reproduzir na VPS

```bash
docker compose -f docker-compose.prod.yml exec -T db \
  psql -U postgres -d postgres -c "select count(*), percentile_cont(0.95) within group (order by duration_ms) from api_request_samples where status between 200 and 399 and created_at > now() - interval '7 days';"
```

Se `count(*)` for baixo (ex.: 1 amostra isolada), **não chamar aquilo de p95** —
esperar a série encher e repetir.
